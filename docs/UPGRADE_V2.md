# 育儿 Agent V2：交付与验收

目标：单家庭、单宝宝、本地/单机运行的可演示版本。不是医疗诊断系统，也不是已完成生产验证的多租户平台。

## 安装

先停止飞书机器人、Streamlit 和其他写数据的程序。安装器只替换代码，先备份被替换的每一个文件；不替换 .env、宝宝数据、照片、家庭成员配置和现有日志。不需要使用上一个 learning_activity_update_fix.zip。

将本包解压到项目目录下的 parenting-agent-v2-upgrade 文件夹。在项目根目录运行：

```powershell
python .\parenting-agent-v2-upgrade\apply_upgrade.py --project . --apply
python -m pytest -q tests_v2
python .\verify_upgrade.py
```

安装器输出备份路径，位于 upgrade-backups 下。仅安装、尚未产生新版数据前，可以用安装器的 `--rollback` 指向该次备份恢复代码；安装后已经运行新版并写数据，不要直接降级，应先保留现有数据和日志另行迁移。

你的未提交代码如被替换，会完整保存在备份中。旧模块 intent/extract/add_record/update_record 等保留，但聊天入口已不再通过它们写入。请不要单独运行旧版写入入口或旧修复脚本；那些不会遵循新版确认/审计规则。

## 新功能

- 六类记录（生长、发育、活动、喂养、健康、回忆）的新增、查询、修改、软删除。
- 照片继续通过网页上传；支持查询、修改照片回忆的文字和日期、软删除及恢复。删除回忆不物理删除照片文件。
- 统一 Command + Selector + values 校验，旧值定位与新值写入分离。
- 所有自然语言写入先预览，再回复“确认”。候选编号选择后仍需确认。
- 日期范围、分类、最新/最早记录、同日并列和无日期边界；数量、奶量或时长统计。
- 稳定ID、按用户/群隔离上下文、20分钟确认过期、跨进程串行提交、冲突拒绝。
- 操作日志保存修改前后值；“操作日志”查询当前会话，“家庭操作日志”查询当前飞书群。
- “撤销上次操作”只撤销本人的最近一次仍可还原的写入，必须确认；他人已改动时拒绝覆盖。
- 飞书 message_id 回执持久化；重复投递不会重复写。回复失败时已写入状态不回滚，可用日志核对。
- 发育/活动/喂养分析与通用知识问答接入现有知识库；回答资料不足时应拒绝推断。

## 数据保护

数据仍是原来的 baby.json。第一次新版访问时，为旧记录补充ID，并保存一份 `baby.before_v2.<编号>.json`；不删除重复记录，不猜测缺失日期。内部 `_agent_v2` 保存上下文、操作日志和消息回执，和业务记录同一次原子替换写入。锁使用同目录SQLite侧文件，仅用于同一台机器上的并发保护；不支持多个云实例共享网络文件夹。

写入前，模型只能创建提议；真正写入由Python执行。每次修改/删除的确认都会重读并比较完整原记录。数据已变化时须重新查询，不能覆盖。文件格式错误则失败关闭，不会用空档案覆盖。

旧版产生的错误套杯记录仍保留。请先查询“宝宝有哪些套杯游戏记录”，明确指出分类/原日期，然后用新版预览确认补日期或删除错误记录。不要仅凭同名自动去重。

## 飞书

```powershell
python .\feishu_bot.py
```

原有APP_ID/APP_SECRET保留。默认仅接受已配置的家庭成员。也可在 `.env` 中配置：

```dotenv
FEISHU_ALLOWED_CHAT_IDS=oc_你的家庭测试群ID
# 可选：在允许的群内进一步限制成员
# FEISHU_ALLOWED_USER_IDS=ou_妈妈的ID,ou_爸爸的ID
```

未知用户不会执行操作。未获授权时，终端显示当前群ID/用户ID，供你核对并加入配置；不会打印App Secret或聊天正文。修改.env后重启。群授权意味着该群成员共用这一份宝宝档案，不能把不同家庭群都加进来。

飞书仍需要你自己的电脑运行、网络可用以及已发布的应用/事件权限。不是24小时云托管；本次不自动发布或修改任何飞书权限。

## 网页

```powershell
python -m streamlit run streamlit_app.py
```

网页会话和飞书会话各自隔离。无登录认证，仅供本机演示，不能公开暴露宝宝数据。刷新新建网页会话不会继承原会话的待确认操作。

## 验证顺序

1. `python -m pytest -q tests_v2`：只测新版核心，完全离线，临时数据，不使用真实API或密钥。
2. `python -m pytest -q`：连同仓库原有测试回归；旧的演示脚本不再当自动测试运行，原RAG生成测试以模拟响应检查边界，不代表真实生成质量。
3. `python -m evaluation.evaluate_v2_parser --live`：明确调用真实DeepSeek API，对22条虚构请求评测；会消耗少量API额度，结果写入 evaluation/results/v2_live_parser_results.json。不会读取/修改真实宝宝记录。
4. 飞书一次完整验收：查询套杯 → 补缺失日期 → 如需则选编号 → 确认 → 查询日期 → 操作日志 → 撤销上次操作 → 确认。两人同时修改同一条时，后确认者应被拒绝并要求重新查询。

## 目前边界（投递时如实描述）

- 模型解析不是100%准确；预览确认是必需的安全边界。没有穷尽所有自然语言表达。
- 一次一条记录、一个操作，不支持一句话跨多个类型批量修改；不做隐式自动合并。
- 不支持语音转录、图片自动识别、视频分析、自动医学诊断或药量建议。
- 对话指代限当前用户/当前入口的近期上下文；不能把其他用户的“那条”借来写入。
- RAG仍采用现有字符TF-IDF检索和现有PDF；本轮未完成原资料全面校核、语义检索升级、医疗安全质量评测。
- 日志保存的是新版实际写入。旧通信日志中的SUCCESS只说明请求回复，不等于历史写入正确。
- 未增加云端部署、备份轮换、数据加密、网页登录、多家庭隔离、全天候运行保障。
- 离线测试数不等于自然语言准确率；真实API、Windows和飞书需本机验收，不可在简历写“100%准确”。

## 简历可使用的项目描述（完成本机验收后）

基于 DeepSeek API 构建育儿记录 Agent，统一结构化命令与数据校验，支持分类/时间条件查询、写入预览确认、多轮歧义消解、操作审计与撤销；通过飞书和 Streamlit 接入，增加用户级上下文隔离、重复消息防重与并发冲突保护，并维护离线回归测试及真实模型解析评测。
