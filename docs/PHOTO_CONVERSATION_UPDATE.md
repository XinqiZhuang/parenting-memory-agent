# 照片自然语言记录更新

上传照片后，直接说日常描述，不需要“照片描述”前缀或“标题=… 分类=…”模板。例如：

> 这是9月15日，我们通过动物模型和认知卡教宝宝认识动物。

程序将文字交给现有 DeepSeek 接口，校验字段后整理为待确认草稿：标题“认识动物”、学习活动、认知分类、用户描述的事件日期和原照片。回复“确认”才新增到档案。群聊的文字仍需 @ 机器人；私聊直接发送即可。

同条图文消息中的文字也会整理为预览。原有按字段填写方式继续可用。

## 后续对话

- 缺日期：只问是哪天，可以直接回答“昨天”“9月15日”或“记不清了”。
- 未写年份：默认家庭时区的当前年份，并在预览提示；修改已有草稿日期时沿用草稿年份。可以明确说“去年9月15日”。
- 日期换算由程序校验，不采纳模型编造的日期；无效日期不写入。
- 预览后可说“日期改成9月16日”“标题改成认识蔬菜”“改成精细动作”。修改后生成新的预览，再确认。
- 纠正请求失败时撤回旧预览、保留照片草稿，避免随后确认过时的信息。
- 多人草稿按群与发送者隔离。消息重复投递不重复保存照片或记录。
- 视觉模型描述只表示画面内容；用户说明实际活动后才按活动分类，不能从一张照片推断首次发生或发育水平。
- 已确认的记录继续使用既有网页编辑或档案修改流程。
