# 2026-09-20 记录管理修复

本次修复在已部署的家庭功能版本上更新，不更换依赖，不改Nginx或环境配置，不自动改写历史档案。

## 功能

- 照片是记录的附件。用户填写的早教、练习、游戏等内容可保存为学习活动，并带活动分类；生活照片仍可保存为回忆。
- 图片识别只描述可见内容，不会仅凭模型识别到卡片或玩具就认定宝宝完成了某项活动。用户填写信息后预览确认。
- “宝宝最近一次大运动/精细动作是什么时候”同时比较学习活动与里程碑；明确问“练习走”查询活动；明确问里程碑仍只查里程碑。
- 照片字段支持空格、中文/英文分号和换行。日期支持真实YYYY-MM-DD、今天/昨天/前天或未知；无效日期返回中文提示，保留草稿。
- 档案总览的时间线、照片墙都增加“编辑”和“删除”。编辑可修改字段及保留哪些照片，先预览再确认。
- 回忆可转为学习活动，保留记录编号、日期、描述、照片。转换、编辑、删除均有审计记录并可撤销；他人改动后的旧预览不可覆盖新记录。
- 飞书可以删除关联到活动的照片记录，也可发送“删除记录 记录编号”。同名多条先选择，再确认。
- 删除是可撤销的记录删除，原始照片文件保留；编辑中移除照片也不物理删除文件。

## 修正已经保存的认动物/认识蔬菜记录

1. 打开家庭网页的“照片墙”或“档案总览”，找到目标记录。
2. 点击“编辑”，勾选“把这条回忆转为学习活动”。
3. 核对活动名称和“认知”分类，点击“预览修改”，再点“确认执行”。
4. 记录会从回忆移动到学习活动，原照片仍显示在照片墙里，不复制出第二条记录。

9月15日的活动出现在9月15日汇总中，不应出现在9月20日汇总。已发送的飞书日报不会被自动修改。

## 飞书照片输入示例

```text
照片信息 日期=2026-09-20 标题=早教活动：认动物 分类=认知 描述=利用动物模型和认知卡带宝宝认识动物
```

请填写真实日期。发送后核对预览，再@机器人回复“确认”。查询和删除：

```text
宝宝最近一次大运动是什么时候
宝宝最近一次练习走是什么时候
删除认动物的照片
删除记录 这里替换为查询结果中的记录编号
```

删除需要再次确认，会删除所选记录及其照片墙展示。只移除其中一张照片时，在网页编辑里取消勾选那一张。
