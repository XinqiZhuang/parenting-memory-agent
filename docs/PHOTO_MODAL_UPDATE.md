# 照片墙菜单与中央弹窗更新

版本：2026.09.21-photo-modal-v4

## 操作方式

- 照片墙不再在卡片下方放编辑、删除按钮。鼠标移到封面照片上，右上角出现圆形省略号菜单；点击后选择编辑或删除。
- 手机与触屏常显右上角菜单；键盘 Tab 聚焦照片或菜单时也显示，Enter/空格可打开。
- 点击照片主体打开中央大图浮窗。同一条记录多张照片时可用上一张、下一张切换；展开卡片中的其他照片也可直接点击查看。
- 档案总览、时间线、每日记录的编辑与删除统一使用中央弹窗。
- 编辑先预览修改，再确认；删除弹窗显示具体记录，再确认。关闭按钮、右上角 X、点击遮罩或 Esc 均不保存，并取消该弹窗的待确认操作。
- 编辑、确认后保留当前筛选与分页。结果用短提示显示，不再在页面顶部展开操作表单。
- 一条记录附带多张照片时，封面菜单编辑或删除整条记录；只移除其中一张可在编辑表单的“保留的照片”中取消选择。
- 删除仍可撤销；其他家庭成员期间修改了同一条记录时，会阻止旧页面覆盖新内容。

## 安装

使用最新 update_family_records.py，兼容原始家庭功能及 records-v1、diary-v2、photo-dialogue-v3 的已知文件版本，保留上一版自然语言照片描述功能。不增加依赖。

将文件上传至服务器 /home/admin/，替换旧同名文件，执行：

```bash
sudo python3 /home/admin/update_family_records.py
```

脚本会备份、离线校验并重启育儿服务；宝宝档案、照片、凭证和作品集不在本次代码替换范围。完成后浏览器 Ctrl+F5 刷新。
