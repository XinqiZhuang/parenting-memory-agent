# 玖玖的成长日记 · 网页与记录管理合并更新

基于已确认的效果图：奶油白、杏桃色、鼠尾草绿；左上宝宝头像与“玖玖的成长日记”；没有小熊、花草等装饰。不新增依赖，不使用外部字体或分析脚本。

## 页面

- 档案总览为默认首页。日期、活动/事件、分类、时长、描述、照片和操作各自分栏。
- 混合类型表格保留奶量、食物、时间、身高、体重、头围、体温等附加信息；CSV 单独导出这些字段。
- 可筛选类型、分类、关键词、日期和缺日期记录；15 条一页。手机上的宽表可以横向滑动，也可切换时间线。
- “新增记录”打开现有对话录入流程，写入仍需确认。每行可编辑和发起删除。
- 照片墙使用三个独立、自适应高度的列呈现瀑布流；照片在上，标题、日期、分类和描述在下。窄屏按列折叠。
- 同一条记录多张照片时，先显示封面，可展开查看其余照片；点击图片可放大。每页18条，避免大量照片同时载入。
- 上传表单默认收起，点击“上传照片”展开。保留识别、手动分类、未知日期和重复提交保护。
- 每日记录单独展示某个发生日期的记录，可编辑、删除并查看汇总文字。
- 对话记录、育儿知识库、推送设置仍保留。定时推送设置不因更新被改变。
- 使用缩小且去除EXIF的显示副本；原文件保留。宝宝记录不进入更新包。

## 安装

仅使用本次最新的 update_family_records.py，不需要再安装上一版。将文件上传到服务器 /home/admin/ 并替换旧同名文件，在阿里云 Workbench 终端执行：

```bash
sudo python3 /home/admin/update_family_records.py
```

脚本检查版本并备份，暂停三个育儿服务，使用临时假数据做离线功能及页面测试，恢复服务并检查 /baby/ 健康接口。失败尝试恢复旧代码，不用备份覆盖现有档案。若提示版本不匹配，保留输出供核对。

安装后刷新 https://xinqizhuang.com/baby/；如旧页面仍显示，请使用 Ctrl+F5 并重新登录。照片墙和档案展示服务器同一份实时记录。作品集及 Nginx 配置不变。

电脑代码可随后用同一文件同步：把文件放进 parenting-agent 目录，在已激活虚拟环境的 PowerShell 执行：

```powershell
python .\update_family_records.py --local
python -m pytest -q
```

此操作不把服务器数据下载到电脑。电脑上的三个服务继续保持关闭。
